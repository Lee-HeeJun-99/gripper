# Optimization identity

30 mm Optuna remains `tools/optimize.py`, gated by the original source/binary fingerprints.
The new static enumeration is NOT Optuna. Only equilibrium/small-rotation outputs are eligible.
Current design dimensions: k and connector count/positions, with E/A/I/length/load fixed per study.
dt is never a design variable. Thickness sensitivity must vary A/I/spacing together for a film interpretation.
Vacuum, tendon, contact-fit and stable-grasp objectives require separate calibrated models; none are reported as achieved.
