## 0. 새 세션에서 바로 알아야 할 사항

- 프로젝트명: **ReGrip — Reconfigurable Modular Variable-Stiffness Gripper**, 작업 적응형 모듈러 가변강성 그리퍼.
- 대회: **MOBIS Robotics Challenge 2027**, 예선 계획서·영상 및 본선 실물 제작 대응.
- 목표 기능: 물체 형상에 유연하게 순응 → 접촉 검출 → 필요한 강성만 부여 → 안전한 파지·이송 → 탈착 가능한 패드·재밍 카트리지 교체.
- 현재 기구 컨셉: **2핑거 기본형, 핑거 100 mm 설계 목표, tendon 구동, PET 적층 + 진공 layer jamming, 교체형 패드와 필름 카트리지**. 원형 베이스 반경 50 mm와 1~8 팁 확장 아이디어는 초기 탐색안이며 2핑거 완성 전에는 우선하지 않는다.
- 현 시뮬레이션: **30 mm 길이, PET 등가 단면 폭 8 mm·두께 0.4 mm/층, 2층, 11 노드/층, X축 방향 보, Z축 하중**, SOFA v26.06. 실제 100 mm 그리퍼·밀폐 챔버·마찰·진공을 아직 모델링하지 않았다.
- 확실한 결과: V1.0.9 FREE + `SparseLDLSolver`의 0.30초 끝단 처짐 **0.0412137916 mm**, X 층간 미끄럼 **0.0008228072 mm**, 마지막 끝단 Z 속도 약 **-0.0143807 mm/s**; **정적 평형은 아님**.
- 독립 Python **정적 선형 FEM**에서 2층 FREE 대비 결합 강성비: `k=0 → 1.000`, `0.01 → 1.00981`, `0.1 → 1.09506`, `1 → 1.72772`, `10 → 3.22826`, `100 → 3.86734`, `1e6 → 3.97021`. 이 값은 **SOFA 결과 또는 실물 재밍 성능이 아니다.**
- C++ 단계: `SOFA_V110_Native_Tangent.zip` 코드 제작. **Windows에서 빌드 실행 시 CMake를 찾지 못해 컴파일 전에 중단**. 성공한 DLL 없음.
- 우선 작업: Ubuntu 네이티브 환경에서 SOFA 버전·컴파일러 확인 → FREE 실행 복원 → C++ 플러그인 빌드 및 로딩 → 미끄럼/강성 재현 → Optuna 자동 탐색. **빌드/물리 검증 이전에 최적값을 주장하지 말 것.**

## 1. 원래 제공한 ReGrip 개발 계획안 검토 및 결론

### 1.1 유지할 설계 방향

- 소프트 핑거로 접촉 형상에 **순응한 후** 진공 압력을 조절해 layer-jamming 강성을 변경한다.
- 와이어 구동과 진공 계통을 분리하며 모터 인코더·전류/장력·진공 압력·접촉 센서를 단계적으로 사용한다.
- 마모성 접촉 패드와 재밍 필름 카트리지를 각각 교체할 수 있도록 한다.
- **2핑거 기본형 우선**; 3핑거/8팁 확장이나 근위·원위 분할 재밍은 확장 항목으로 둔다.
- 초기 제어는 강화학습이 아닌 **FSM + 위치/장력 제한 + 압력 제어 + 안전 인터록**으로 시작한다.
- 검증 지표는 파지 성공률 단독이 아니라 미끄럼, 물체 최대 접촉력, 압력·장력, 강성 전환비, 파지 시간, 손상·누설·반복 조립성을 함께 본다.

### 1.2 반드시 수정·보완할 부분

1. **실제 진공 재밍 미구현**: 30 mm 보의 연결 강성 파라미터 `k`는 실제 진공 압력이나 마찰계수로 보정되어 있지 않다. `k`와 압력 `P`를 임의로 동일시 금지.
2. **강성비 기준 명확화**: 같은 2층에서 완전 슬립 FREE 대비 완전 접합 BOND 이상 모델의 굽힘 강성비는 약 **4배**. 단일 0.4 mm 층 대비 완전 접합 0.8 mm 층은 약 **8배**. 비교 기준을 바꾸어 수치를 혼용하지 말 것.
3. **기구 크기 불일치**: 현재 SOFA 보 **30 mm** ≠ 목표 핑거 **100 mm**. 강성·처짐·좌굴·장력·접촉력은 길이에 민감하므로 30 mm 결과를 100 mm에 단순 외삽하지 말 것.
4. **재료 계수 미확정**: 기존 소스의 `E=250`, `NU=0.32` 및 보의 질량·하중은 연구용 코드 값. 단위계(길이 mm, 힘 단위 등), 실제 PET의 방향별/온도별 물성, 필름·외피·챔버 합성강성은 별도로 확정해야 한다.
5. **물리 계층 분리**: (a) 보 굽힘 (b) 층간 전단 결합 (c) 진공 압력과 마찰/접촉 (d) tendon 구동 (e) 물체 파지·마찰·변형 (f) 센서 FSM 순으로 통합해야 한다. 현재 a는 기준 동적 응답이 확인됐고 b는 Python 정적 모델만 확인됐다. c~f는 미구현 또는 별도 초기 실험 수준.
6. **접촉력과 강성의 구분**: 강성 증가가 곧 파지력 증가나 물체 보호를 뜻하지 않는다. 파지 안정성 및 손상 저감은 실물/물체 접촉 조건 비교로 검증해야 한다.
7. **CAD/제작 검증 부족**: 교체 카트리지의 필름 고정, 진공 누설, 씰, 포트, 패드 마찰, 와이어 마찰/마모, 모터-와이어 경로, 베이스 장착 인터페이스, 부품 BOM이 아직 확정된 설계가 아님.
8. **대회용 범위 관리**: 2027 예선은 계획서 + 영상으로 평가. 본선 키트·실물 제작 제약의 상세 사양을 확인하기 전에는 진공 펌프, 배관, 액추에이터 장착 가능 여부를 확정 서술하지 않는다.

### 1.3 출품용 차별화 표현(검증 전에는 가설)

- 새 원리의 최초 발명이 아니라 **모듈별 교체성 + 작업 조건별 가변강성 제어 + 압력·접촉력·미끄럼을 함께 최적화**하는 시스템 수준 접근.
- 예선 핵심 메세지: **형상 순응을 먼저 하고, 과도한 힘 없이 필요한 순간에 필요한 수준의 강성만 제공**.
- 후보 B(교체형 카트리지) + C(접촉 기반 강성 선택)를 핵심으로, A(분할 재밍)는 확장안.
- 정량 검증 전까지 '접촉력 감소', '성공률 향상', '최적압력 도출'을 완료 성과로 쓰지 않는다.

### 3.1 별도로 보관해야 할 원본 수치

**V1.0.9 FREE 검증 기준(0.3초, dt=0.0005):**
- 끝단 처짐 `0.04121379160634629 mm`
- Z 끝단 속도 `-0.014380704053554308 mm/s`
- 최대 X 미끄럼 `0.0008228072034270895 mm`
- 최대 Z 상대 변위 `8.462655126939556e-07 mm`
- 상태 `COMPLETE`(정적 평형 인증 아님)

**V1.0.6 정적 기준(자유 2층 대비):**
- k=0: 처짐 `0.0421875 mm`, 강성비 `1.0`, 미끄럼 `0.00084375 mm`
- k=0.01: 처짐 `0.0417777105`, 비 `1.0098088`
- k=0.1: 처짐 `0.0385253224`, 비 `1.0950590`
- k=1: 처짐 `0.0244180443`, 비 `1.7277182`
- k=10: 처짐 `0.0130681935`, 비 `3.2282580`
- k=100: 처짐 `0.0109086558`, 비 `3.8673418`
- k=1e6: 처짐 `0.0106260058`, 비 `3.9702124`
- **주의:** V1.0.6은 정적, V1.0.9 FREE 0.3초는 동적 과도상태이므로 처짐 수치가 다른 이유를 `오류`라고 단정할 수 없다.

### 3.2 기술적으로 열려 있는 문제

- `CGLinearSolver`에서 수렴/잔차/매핑된 강성 조립이 제대로 이루어졌는지 미확인.
- `SparseLDLSolver`가 Python 사용자 정의 ForceField를 강성 행렬로 조립할 때 크래시; C++ 구현으로 전환했으나 ABI/API 미검증.
- SOFA `Rigid3d`는 위치 3 + 쿼터니언 방향 4로 저장하지만 힘·접선 미분 DOF는 6이다. 회전 자유도·부호·행렬 조립을 실제 SOFA API로 점검해야 한다.
- 연결점의 **접선 X 상대변위/회전 모멘트**는 작은 회전 가정이고, 큰 굽힘·접촉·마찰은 아직 물리적으로 모델링되지 않았다.
- 고강성 성공 시에도 마지막 속도·잔차·시간간격 수렴·힘-변위 선형성 체크 없이 `정적 강성`이라 주장하지 말 것.
- `k`의 단위와 실제 필름 인터페이스(면적·연결점 spacing·압력·마찰·온도) 사이 매핑 미확정.

## 5. 현재 수학 및 물리 모델

### 5.1 보 FEM(검증 기준)

- 2개의 독립 PET 등가 보 (11 nodes/each; 총 22 Rigid3d DOFs), length 30 mm, width 8 mm, each thickness 0.4 mm, separation h=0.4 mm.
- E=250, ν=0.32 (연구용 모델 값), 각 루트 고정, 끝단에 총 Z 하중 `F=0.0001`을 절반씩 가함.
- BeamFEMForceField, EulerImplicitSolver, SparseLDLSolver, dt=0.0005 s, 0.30 s 동적 기록.
- **근본 단위계 확인:** mm, 질량, 힘, 시간의 일관성을 코드 상·실험 상 검증한다.

### 5.2 접선 전단 에너지(이상화 모델)

접촉면의 작은 회전 가정에서 연결쌍 i의 미끄럼:

`si = (xu_i − xl_i) − (h/2)·(θy,u_i + θy,l_i)`

`E_shear = 1/2 Σ ki si²`

`f = −∂E/∂q`,  `∂f/∂q = −k bᵀb` (`b=[−1,−h/2,+1,−h/2]`)

- X축 접선 상대 변위만 직접 구속하고 Y/Z 법선 힘은 직접 추가하지 않음.
- 보의 회전 DOF에는 모멘트가 전달되어야 한다.
- **회전 좌표계/부호 검증 중요:** C++ 코드에서 `theta_y ≈ 2*q_y`를 사용한 작은 회전 선형화가 SOFA의 좌표 표현 및 에너지 미분과 일치하는지 실제 컴파일 이후 유한차분/행렬 검사 필요.
- **작은 회전만 유효**. 100 mm 그리퍼의 큰 곡률 및 tendon 구동에서는 exact rigid contact kinematics와 consistent tangent stiffness로 확장해야 한다.

### 5.3 실제 layer jamming으로 확장할 때

`진공압력 P → 압착 법선응력 σn → 층간 마찰한계 μσn → slip/stick 전환 및 이력`의 물리 모델과 누설·필름 굽힘·계면 면적을 추가한다. **현재 선형 스프링 상수 k는 물리적 진공압력 P가 아니다.**

필요한 실험: 진공 OFF/ON/다중 압력의 힘-변위 곡선, 히스테리시스, 반복성, 누설률; 실물 시제품에서 k 또는 마찰 모델 보정.

### 7.3 최적화 범위(물리 검증 완료 후 단계적으로)

**Stage 1 — 모형 연결 최적화**: `k`, connector positions/spacing, node count, layer thickness, numerical damping(물리 목적함수와 별도 분리). `dt`는 물리 설계 변수 아닌 **수치 수렴 검증 변수**로 취급.

**Stage 2 — 기구 설계 최적화**: 길이 100 mm, 2핑거, PET 층수, 필름 두께, 카트리지 배열, 와이어 경로/장력, 간섭·조립성.

**Stage 3 — 재밍 실험 모델 최적화**: 실측 기반 `pressure → friction/stiffness` 보정, 압력 선택, 동특성, 누설, 접촉 패드.

**Stage 4 — 실제 파지 최적화**: 물체 크기·질량·재료별 안전 파지, 미끄럼·최대 접촉력·하중 유지·손상 비교, FSM 제어 파라미터.

**단순 목적 함수 예시 (시뮬레이션 선행 검증용):**

`maximize J = w1·(K_ON/K_OFF) − w2·slip_ON − w3·contact_force_peak − w4·actuation_energy`

단위가 다른 항목은 정규화해야 하고, 압력·응력·파지 안정성·실시간 제약 등은 **제약조건**으로 별도 둔다. 접촉력은 현재 정적 보 모델에서 계산하지 못하므로 Stage 1의 목적함수에 가짜 0을 넣지 않는다.

## 9. 검증 데이터 및 실험 프로토콜 (최소 기준)

### 9.1 물리 검증

- FREE, 소규모 K, 중간 K, 높은 K; 같은 하중·보 구조·측정 시간 유지.
- 정적 평형: 마지막 구간 속도 및 평형 잔차 기준 충족, 연장 실행 시 처짐 변화 충분히 작음.
- 최종 강성: `K_eff = F / δ_equilibrium`; 평형 전 값으로 계산하지 않는다.
- 마찰 재밍에 대한 압력별 강성: 실측 피드백 보정 뒤에만 보고.
- 연결점 간격, 보 노드 수, dt, 시간 적분/솔버의 민감도 및 물리 단위 재검증.

### 9.2 실물 제작 검증

- 2핑거, 100 mm 목표 형상, 교체형 팁·패드·진공 카트리지의 장착 반복성.
- 진공 OFF/ON 압력 단계별 주어진 힘에서 팁 처짐, 최대 곡률, 변형 회복, hysteresis.
- 그리퍼 접촉 테스트: rigid/fragile/irregular 물체, 같거나 비슷한 파지 안정성에서 최대 압력과 슬립 비교.
- 내구성: 반복 굽힘, 필름 층간 마모, 패드 마모, 밀폐 누설, 케이블 피로, 전원/진공 상실 시 안전.

### 9.3 보고 원칙

결과를 **[측정] / [모델 예측] / [설계 가설] / [향후 계획]** 네 분류로 명시한다. 출품 자료에서 유효하지 않은 실험·큰 변위 수치 발산·미수렴 상태를 성능 성공으로 표현하지 않는다.
