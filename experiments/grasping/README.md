# Grasping scope

Only an ideal eccentric terminal moment and planar tip penalty contact are implemented in static FEM.
Contact has a known compliance and an analytical reference; it is not a 3D object or stable grasp solver.
Vacuum friction is a separate prescribed-pressure elastic/plastic slider with dissipation.
Finger count, body radius, cartridge shell, real wire path, sealing and 3D object geometry remain research inputs.
