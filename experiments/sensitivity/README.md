# Sensitivity

`tools/next_experiments.py static` performs ±20% one-factor research perturbations of L,h,E,A,I,k,F.
These are assumed uncertainty bands, NOT measured confidence intervals. Independent EA/EI/spacing changes
are distinct from geometry-consistent thickness changes (A∝t, I∝t³, centroid spacing∝t).
Do not mix sensitivity outputs with optimizer trials or certified 30 mm regressions.
