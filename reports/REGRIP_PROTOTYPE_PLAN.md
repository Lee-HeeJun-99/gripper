# 수동 골판지 작동원리 시연 — 실물 레이어 재밍 인증 아님

목적:넓은 접촉면의 감싸기,교체 카트리지,유연 적응과선택적 잠금의 분리를
보인다. 모터/3D프린팅/완제품 그리퍼는 사용하지 않는다.

## 제작 후보와 작동

- 골판지 원형/삼각 palm과 긴 손잡이,탈착 가능한3개의 종이/골판지 strip.
- 골판지의 길이방향 접힘선으로 굽힘부를 만들고,넓은 종이 접촉띠를 덮는다.
- 빨대 조각은 양쪽 edge string guide,실은손잡이의수동당김 equalizer로 연결.
- 고무줄은복원. 테이프는고정부/외피,움직이는레이어전체를접착하지 않는다.
- 선택적 잠금 시연은 근위 구간을 별도 실 belt와 골판지 wedge에 수동으로
  묶어마찰고정한다. 이는 **기계적 잠금 analog**이지진공 레이어재밍이 아니다.
- 카트리지는골판지 tab/slot+테이프고정으로교체. 잡은상태에서갑자기풀리지
  않도록낙하받침을두고손가락을핀치영역에넣지않는다.

예시 검증 대상은 가벼운 빈 종이컵/상자(강체근사)와 접은 천/스펀지(유연체).
실·케이블은추가시연가능. 깨지는유리/무거운물체는사용하지않는다. 취성물은
요구2종을이미만족하므로불필요한파손위험을추가하지않는다.
